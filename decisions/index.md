# Decision index

This index separates current working decisions from research and proposals.
It is intentionally small: an entry is added only when a choice should guide
future work or when an unresolved question needs a stable handle.

## Status vocabulary

- working — applied in the current pilot, but still open to owner review;
- open — unresolved question; do not treat it as policy;
- approved — explicitly accepted by the owner;
- superseded — replaced by a newer decision.
