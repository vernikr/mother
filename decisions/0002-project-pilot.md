# 0002 — Current GitHub Project pilot

**Status:** working; applied to organization Project 1 and pending broader
methodology approval.

## Working decision

The Project uses:

- statuses: `Inbox`, `Ready`, `In Progress`, `Blocked`, `Done`;
- views: `All work`, `Queue`, `Blocked`;
- organization-level `Business Value` Issue field on a 0–5 numeric scale;
- the built-in `Repository` field for cross-repository scope;
- GitHub Issues as semantic work items and the Project as their operational
  status projection.

There is no separate `Verify` status in the pilot. Verification is represented
by required evidence in the Issue and checks attached to the work.

## Deliberately not baseline

`Risk`, calendar fields, `Priority` and `Agent state` are not approved baseline
fields. Their future use requires a separate decision.
